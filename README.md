# Exercício 3 — Página de Pagamento

Projeto desenvolvido para a atividade de JavaScript do SENAC.

## Estrutura

- `index.html` — estrutura da página.
- `css/style.css` — estilos.
- `js/script.js` — interações, validações e cálculos.
- `img/` — imagens/ícones das bandeiras.

## Regras implementadas

- Seleção entre PIX e Cartão de Crédito.
- Apenas uma forma de pagamento é exibida por vez.
- Validação do valor da compra.
- PIX com 10% de desconto.
- Validação de CPF.
- Cartão iniciado em `1234` ou `4321`.
- Mensagem de cartão inválido para outros prefixos.
- Exibição de ícone da bandeira conforme o prefixo.
- Parcelas de 1x a 5x.
- 4x com 5% de juros.
- 5x com 10% de juros.
- Atualização automática do total e valor da parcela.
- Validação dos campos do cartão.
- Mensagem de pagamento realizado com sucesso.
